Put a landing page on WordPress in one import

Download the file for a page, import it, and the page, its images and its settings arrive as a private draft. Nothing is built by hand and nothing goes live by itself.

Four steps, for each page

  1. Download the import file for the page above. It is one .xml file.
  2. In WordPress admin go to Tools, Import, WordPress. If it offers to install the importer, say yes. Choose the file, pick yourself under Assign posts to an existing user, tick Download and import file attachments, and untick Rewrite URLs (it is ticked by default and it turns every in-page link into a link to the home page). Run it. It takes a minute or two because it fetches the images.
  3. Open the new private page. Check it next to the review page (the link on the card), on a phone and on a laptop.
  4. Fill in the three things below, then publish when Kate says go. Purge LiteSpeed after.

Importing the same file twice makes a second copy of the page, not a replacement. Delete the old one.

Three things only you can fill in

The form address. In the page, search for __FORM_ENDPOINT__ (it is in the last Custom HTML block) and put the address that receives the booking form. Until then the form does nothing and says it is a preview.
Page address and language. The slug is set. Choose the parent page and set the language to English in WPML.
Search engines. The pages arrive set to noindex. Switching that off in Yoast is the launch decision, so leave it until Kate says.

If something does not work

The import is missing the importer, or fails on images

Install WordPress Importer from Plugins, Add New. If images fail, the server could not reach trk-salon-os.com: run the import again, or tell Kate.

I would rather paste the page in by hand

Use Copy the blocks on the card. Make a new private page, open the three dots menu, choose Code editor, paste, and switch back to the Visual editor. Import the file once anyway to bring the images in. Then in the page settings switch the site header, navigation, title and footer off, because the page has its own.

The menu and buttons on the page jump to the home page

Rewrite URLs was left ticked on the import screen. Delete the imported page and its images are fine to keep. Import the file again with Rewrite URLs unticked.

The editor says a block is invalid

Do not fix it by hand and do not choose “Attempt block recovery”. Tell Kate: the build has to change, not the page.

The page copy changed after I imported

The files here are rebuilt from the review page, so download again. The date under the cards shows when it was last built. Do not edit the copy in WordPress, it will be overwritten next time.
