QR Code Maker

Make a QR code with Tara Rose Salons or tararosesalon.com in the middle. One at a time, or paste a whole list. Save the ones you will want again.

To name each code, put the name first and then a | or a tab (a column pasted from Sheets works): Name | link. The name is used for the file name.

Always scan it with a phone before it goes to print. A short link makes a cleaner code; the middle picture and the error correction are set so it still scans.
